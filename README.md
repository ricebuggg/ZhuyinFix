# ZhuyinFix

忘記切輸入法、把注音打成一串英數亂碼？選起來按 **Ctrl+Shift+Z**，直接還原成中文。
全 Windows 通用（Slack、Outlook、Teams、記事本、瀏覽器都行），離線運作，不上傳任何文字。

```
su3cl3          →  你好
ji394t au04     →  我愛吃麵
5j/ 2k7 ticket 2j/ vu   →  中的ticket東西      （夾在中間的英文會原樣保留）
```

## 安裝

1. 下載本專案（Code → Download ZIP）解壓到任一資料夾，例如 `C:\Tools\ZhuyinFix`
2. 雙擊 **`install.bat`**
   - 沒有 Python 也沒關係，它會自動安裝 [uv](https://docs.astral.sh/uv/)（約 20 MB）
   - 會在「啟動」資料夾放一個捷徑，之後開機自動在背景跑
3. 完成。第一次啟動會多花幾秒下載套件（pynput、pystray、pillow）並建立詞庫快取，之後啟動 <0.2 秒。工作列右下角會有一個「注」圖示

移除：雙擊 `uninstall.bat`。

## 使用

| 按鍵 | 動作 |
|---|---|
| **Ctrl+Shift+Z** | 還原亂碼。有選取文字就轉選取的那段；沒選取就自動抓整行，只換掉行尾的英數亂碼，前面已打好的中文不動 |
| **再按一次 Ctrl+Shift+Z** | 進入選字模式（游標旁的小框）；不進選字直接繼續打字或按 Enter，小框自動消失 |
| **Esc**（小框還在時） | 復原：把剛轉好的中文換回原本的英數 |
| ← → | 移到要改的字 |
| ↑ ↓ | 在同音字候選裡移動 |
| Enter 或 1~9 | 確定候選字並跳到下一個字；候選 1 永遠是原本的字，所以一路按 Enter 就是「都不換」 |
| Space | 候選字下一頁 |
| Esc | 結束選字 |

### Enter 自動偵測

沒按快捷鍵、直接按 Enter 時，如果剛打的那一串很像注音亂碼（≥4 個音節、每段都拆得出合法音節、有聲調、詞庫全認得），程式會先攔下 Enter 自動轉換，小框會標「已自動轉換」。看一眼沒問題再按 Enter 送出，錯了按 Esc 復原。輸入法在中文模式時不會偵測（那時你打的英數本來就是注音鍵，Enter 是在選字）；英文句子過不了「有聲調 + 全合法音節」這兩關，實測 `hello world`、`the quick brown fox 123` 都不會被誤攔。不想要可在系統匣選單關掉。

小框也可以用滑鼠點。8 秒沒動作會自己消失。

### 上下文

沒選取、抓整行時，行首已經打好的中文會當上下文：候選詞裡含有同一行出現過的字會加分。例如前面打了「這段程碼」，後面亂碼 `t/6g4` 會出「程式」而不是「城市」。加分幅度固定（log 機率 +1.5），詞頻差超過約 4.5 倍就不會翻盤，避免亂加。

### 系統匣

右下角「注」圖示右鍵：啟用/暫停、開關 Enter 自動偵測、開 log、開資料夾（改 `user_phrases.csv` / `learned.csv`）、重新啟動、結束。

注意：換字是靠「把剛貼上的那段選起來重貼」，所以要選字請在轉換後**馬上**做，不要先在後面繼續打字。

## 自動學習

跟輸入法一樣，但比較保守：選字結束時，只學「真的被你改過的字」和它與相鄰字組成的 2 字詞。同一組注音**第一次**選某結果只加分（詞頻 20000，還壓不過常用詞），**第二次**選同一結果才置頂（500000）。這樣一次誤選不會把常用詞壓死。學錯了打開 `learned.csv` 刪掉那一行即可（第 4 欄是次數）。

優先順序：`user_phrases.csv`（手動釘的）＞ `learned.csv`（自動學的）＞ 內建詞庫。

## 自訂詞

`user_phrases.csv`，一行一個：

```
詞,999999,注音（音節用空白分開）
吃麵,999999,ㄔ ㄇㄧㄢˋ
```

詞頻填 999999 就會壓過內建詞庫，適合放同事名字、站點代號等常打的詞。改完在系統匣圖示右鍵「重新啟動」即生效。

## 準確率

`bench.py`：從詞庫隨機抽真實詞組成 500 句，反推應打的鍵位再還原比對。

| 指標 | 結果 |
|---|---|
| 整句正確 | 85.4% |
| 逐字正確 | 96.7% |

（bench 是隨機拼詞，沒有上下文，所以上下文加分在這裡量不出來；實際整行輸入會更好。）

錯的幾乎都是同音詞挑了較常見的那個（雷射/鐳射、一頁/一葉），新注音也會這樣，選字模式一鍵可修。

## 限制

- 鍵盤對照是**大千（標準）注音鍵盤**；許氏、倚天等其他排列要改 `zhuyinfix.py` 的 `KEYMAP`
- 判斷「哪段是亂碼、哪段是真英文」的規則：以空白切段，某段拆出不合法音節或含大寫就當英文保留（例外：整段字母全大寫 = Caps Lock 開著打的，會當小寫轉）。純小寫且剛好每個字母都能湊成音節的英文單字（少見）會被誤轉，選字時看一眼就知道
- 快捷鍵寫死 `Ctrl+Shift+Z`，衝到的話改檔頭 `HOTKEY`
- 只支援 Windows（用了 Win32 API 做不搶焦點的候選框與按鍵攔截）

## 原理

1. 英數 → 注音：鍵盤一對一對照，聲調鍵（3/4/6/7/空白）切音節，漏打空白時靠「聲母/介音/韻母順序倒退」自動斷音
2. 注音 → 中文：[libchewing](https://github.com/chewing/libchewing-data) 新酷音詞庫（12 萬條、含詞頻）+ Viterbi 找機率最高的詞串
3. 貼回：直接呼叫 Win32 剪貼簿 API（不經 pyperclip），用剪貼簿序號判斷 Ctrl+C 完成，不靠固定等待；貼上後 0.4 秒還原原本的剪貼簿內容
4. 標點：夾在亂碼裡的 `< > ? ! :` 轉成 `，。？！：`
